- تغییر پرسنل «علی بوستان افروز»:
  - مقدار اولیه: `EN`

  - تغییر به `EN` → کد ۲۰۰ → مقدار ذخیره‌شده: `EN`

- مقدار اولیه: `EN`
- `EN → ME`: کد ۲۰۰، مقدار تأییدشدهٔ `ME`
- `ME → EN`: کد ۲۰۰، مقدار تأییدشدهٔ `EN`

نتیجه: ذخیره‌سازی و ماندگاری در پروفایل در هر دو نسخه تأیید شد.
